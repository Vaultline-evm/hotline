# Vaultline Wallet

محفظة EVM محمولة مبنية باستخدام Expo SDK 54 وReact Native وTypeScript. تستورد المفتاح الخاص فقط على iOS أو Android، وتشتق عنوان EVM محليًا، ثم تعرض الأرصدة والأسعار التقديرية وسجل النشاط. واجهة التطبيق عربية وRTL.

## الميزات

| المجال | ما يقدمه التطبيق |
|---|---|
| إدارة المحافظ | إضافة عدة محافظ بمفتاح خاص فقط، اشتقاق العنوان محليًا، وتبديل المحفظة النشطة |
| حماية المفتاح | تخزين المفتاح في Expo SecureStore (iOS Keychain / Android Keystore). لا يحفظ المفتاح في AsyncStorage ولا يرسله التطبيق إلى RPC أو الخادم |
| الأصول | 13 شبكة EVM و24 رمزًا ضمن بيانات العرض؛ الإرسال مقيّد بالأصل الأصلي وعقود ERC-20 المحددة لكل شبكة في `lib/wallet.ts` |
| الإرسال | تقدير الغاز والرسوم وفحص الرصيد، ثم نافذة مراجعة إلزامية؛ يتم التوقيع على الجهاز ولا تُبث إلا المعاملة الموقعة |
| السجل | نشاط محلي ومعاملات مسترجعة بحسب توافر مستكشف الشبكة، مع روابط للمستكشف |

لا توجد عمولة تطبيق منفصلة في قواعد المصدر المنقولة؛ المبالغ المعروضة في مراجعة الإرسال تتضمن رسوم الشبكة التقديرية. أسعار السوق تحويلات عرضية وليست جزءًا من احتساب الرسوم أو التوقيع.

## التشغيل محليًا

```bash
pnpm install
pnpm exec expo start
```

امسح رمز QR من Expo Go أو استخدم development build متوافقًا مع SDK 54.

وظائف إدخال المفتاح والتوقيع معطّلة في الويب عمدًا. افحص الأنواع والاختبارات وlint بالأوامر:

```bash
pnpm check
pnpm test
pnpm lint
```

## EAS Build

يوجد ملف [`eas.json`](./eas.json) في جذر المشروع. من مجلد المشروع نفسه (المجلد الذي يحتوي `package.json` و`eas.json`)، سجّل الدخول مرة واحدة واربط المشروع بحساب Expo إذا طُلب ذلك، ثم أنشئ APK داخليًا للتجربة أو بناءً إنتاجيًا:

```bash
npx eas-cli login
npx eas-cli build --platform android --profile internal
npx eas-cli build --platform android --profile preview
npx eas-cli build --platform android --profile production
```

ملفا `internal` و`preview` يخرجان APK للتثبيت الداخلي؛ ويورث `internal` إعداداته من `preview`. أما `production` فيستخدم إعداد Android الافتراضي الملائم للمتجر ويزيد رقم البناء تلقائيًا. يتطلب النشر توقيعات Android أو إعداد حساب Apple وملفاته على iOS؛ إضافة `eas.json` تحل خطأ غياب الإعداد لكنها لا تنشئ بيانات اعتماد المتاجر. تصدير Metro وحده لا ينشئ ملف متجر.

## الشبكات والتوافر

توجد إعدادات 13 شبكة في `lib/wallet.ts`. تعمل نقاط RPC العامة حسب التوافر وسياساتها. Palm ظاهرة في القائمة لكن لا توجد نقطة RPC عامة بلا مفتاح مؤكدة في الإعداد الحالي؛ لذلك قد لا تتوفر بياناتها أو الإرسال عليها. عنوان Blast الرسمي مدرج، لكن ينبغي اختبار اتصاله من شبكة التشغيل المستخدمة. تفاصيل المطابقة ونتائج التحقق محفوظة في [`source-parity.md`](./source-parity.md).
